9//! This library provides types to represent an IP network ([`Cidr`]) or
10//! an IP host withing a network ([`Inet`])
11//!
12//! The naming follows the names of the [PostgreSQL data types](https://www.postgresql.org/docs/current/static/datatype-net-types.html)
13//!
14//! By default address parsing is done using `FromStr` from the standard
15//! library, which is rather strict in the inputs it accepts.
16//! [`Cidr`] types don't accept addresses with host-bits set (i.e. `127.0.0.1/8`
17//! isn't valid; it should be `127.0.0.0/8`).
18//!
19//! Custom parsing can be implemented using the helpers in the [`parsers`] module.
20//!
21//! If the `#` flag is used with the `Display` formatting (i.e. `{:#}`) the
22//! prefix length will be shown even for host addresses (added in `0.1.1`).
23//!
24//! # Feature `no_unsafe`
25//!
26//! Enables `#![forbid(unsafe_code)]` for the whole crate; needs to use
27//! some workarounds that are likely slower than their `unsafe` variants.
28//!
29//! # Feature `std`
30//!
31//! Enabled by default, currently unused.
32//!
33//! # Feature `serde`
34//!
35//! This feature enables various types to be serialized using `serde`
36//! (without `serde-derive`).
37//!
38//! In human readable formats the `Display` and `FromStr` interfaces are
39//! used.  Otherwise all values are serialized in the same format (apart
40//! from the newtype wrapping) as a tuple of two values:
41//!
42//! - `tag: u8`:
43//!   - `0x00...0x20`: IPv4 with network length `tag`
44//!   - `0x40...0xc0`: IPv6 with network length `tag - 0x40`
45//!   - `0xff`: `any`
46//! - address according to `tag`: [`Ipv4Addr`] (`[u8; 4]`), [`Ipv6Addr`]
47//!   (`[u8; 16]`) or `()`
48//!
49//! The represenation hasn't been changed in 0.2; it is compatible with 0.1.
50//!
51//! # Feature `bitstring`
52//!
53//! This feature allows various types to be used as [`bitstring::BitString`],
54//! which allows them being in used in containers like [bitstring-trees].
55//!
56//! [bitstring-trees]: https://crates.io/crates/bitstring-trees
57//!
58//! [`Ipv4Addr`]: core::net::Ipv4Addr
59//! [`Ipv6Addr`]: core::net::Ipv6Addr
